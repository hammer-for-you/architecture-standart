### <a name="_3bfxc9a45514"></a>**Функциональные требования**

| **№** | **Действующие лица или системы**                            | **Use Case**                             | **Описание**                                                                                                                                                                                                                                                                                                                                     |
|:-----:|:------------------------------------------------------------|:-----------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|  UC1  | Клиент, сайт, менеджер кол-центра                           | Подача заявки на депозит (сайт)          | 1. Клиент переходит на сайт банка<br/>2. Клиент вводит своё ФИО и телефон на форме заявки на открытие депозита<br/>3. Заявка регистрируется в системе кол-центра<br/>4. Пользователю звонит менеджер кол-центра и договаривается об условиях<br/>4. Менеджер кол-центра формирует заявку на открытие депозита и отправляет её в сервис депозитов |
|  UC2  | Клиент, сервис депозитов, интернет-банк                     | Персональные предложения депозитов       | 1. Клиент заходит в интернет-банк<br/>2. Интернет-банк обращается в сервис депозитов за ставками<br/>2. Интернет-банк показывает ему  список доступных депозитов с актуальными ставками и персонализированные ставки лично для пользователя                                                                                                      |
|  UC3  | Клиент, интернет-банк, СМС-шлюз, сервис депозитов           | Подача заявки на депозит (интернет-банк) | 1. Клиент отправляет заявку на депозит, указав счёт и сумму депозита<br/>2. Система запрашивает подтверждение посредством СМС через СМС-шлюз<br/>3. После подтверждения в сервисе депозитов формируется заявка на депозит                                                                                                                        |
|  UC4  | Клиент, интернет-банк, сервис депозитов                     | Проверка статуса заявления               | 1. Клиент заходит в интернет-банк<br/>2. Интернет-банк запрашивает в сервисе депозитов данные о заявках на депозит<br/>3. Клиент видит статус своих заявок на открытие депозита                                                                                                                                                                  |
|  UC5  | Сервис депозитов, менеджер бэк-офиса, АБС, СМС-шлюз, клиент | Открытие депозита                        | 1. Сервис депозитов передаёт заявку на открытие депозита в АБС<br/>2. Менеджер бэк-офиса получает новую заявку на открытие депозита<br/>3. Менеджер подтверждает условия депозита в АБС<br/>4. АБС через СМС-шлюз отправляет клиенту СМС-подтверждение об открытии депозита<br/>5. АБС обновляет статус заявления в сервисе депозитов            |

### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**

| **№** | **Требование**                                                                                             |
|:-----:|:-----------------------------------------------------------------------------------------------------------|
|  R1   | Все сервисы работают в режиме 24/7                                                                         |
|  R2   | Сервисы доступны в 99,9% случаев                                                                           |
|  R3   | Работа со ставками по депозитам реализована в АБС                                                          |
|  P1   | Отклик интерфейса - несколько миллисекунд                                                                  |
|  P2   | Скорость загрузки справочных данных при проведении операций оптимизирована для быстрого отклика интерфейса |
|  P3   | Возможность горизонтального масштабирования                                                                |
|  +R1  | Работа с депозитами осуществляется в отдельном сервисе на Java Spring Boot                                 |
|  +R2  | Сервис депозитов работает с собственной базой MSSQL                                                        |
|  +R3  | Синхронизация базы депозитов и АБС осуществляется при помощи RabbitMQ                                      |
|  +R4  | Справочные данные кэшируются в Redis                                                                       |
|  +R5  | Сервис депозитов, кэши и БД сервиса депозитов разворачиваются в Kubernetes                                 |
